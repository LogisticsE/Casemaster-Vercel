cms-vercel — live demo

This deployment is the canonical example of running a CaseMaster .cms application on Vercel via the cms-vercel runtime. Every link below is generated from real .cms files in the repo's app/ directory, served by a single 5-line Vercel Function.

Demo pages

  • /page/foo/f/hello — full HTML page with template substitution
  • /page/foo/f/ping — DB connectivity check, returns ok N

Auto-generated CRUD (no UI code, just BO declarations)

  • /maintenance/qr/labelTemplate — QR label templates
  • /maintenance/qr/job — QR jobs
  • /maintenance/qr/code — QR codes
  • /maintenance/axylog/trip — Axylog trips
  • /maintenance/axylog/document — Axylog documents
  • /maintenance/axylog/party — Axylog parties
  • /maintenance/axylog/visit — Axylog visits
  • /maintenance/axylog/customerVisit — customer visit view
  • /maintenance/axylog/tripSummary — trip summary view
  • /maintenance/axylog/ingestRun — ingest run history
  • /maintenance/axylog/contextOwner — context owners (multi-tenancy)

Diagnostic endpoints

  • /api?diag=1 — registry health, app dir, env presence
  • /api?stats=1 — function counts + warm-instance status
  • /static/css/app.css — static asset (theming)
